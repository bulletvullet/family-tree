# Семейное древо

Локальное веб-приложение для ведения семейного древа: таблица людей,
связи родитель–ребёнок, автоматические статусы родства («2П дедушка»,
«3Ю сестра», невестка, теща и т.д.) и интерактивный 3D-граф.

## Запуск

```bash
python3 server.py        # http://localhost:8791/
```

или двойной клик по `start.command` (macOS).

- Данные хранятся в SQLite (`data/family.db`) + резервная копия в localStorage.
- Даты могут быть неполными: `ГГГГ`, `ММ-ГГГГ` или `ДД-ММ-ГГГГ`.
- «Зелёный» человек (свитчер «Фокус») — центр, относительно него
  считаются статусы родства в таблице.

## Публичная страница «только дерево»

Каталог `deploy/tree/` — автономная статическая страница с интерактивным
3D-древом (вращение, зум, клик по человеку). Данные читает из `people.json`
рядом со страницей (в репозитории его нет — это персональные данные;
есть `people.example.json` для примера).

Обновление публичного дерева:

```bash
curl -s http://localhost:8791/api/people > deploy/tree/people.json
rsync -az deploy/tree/ user@host:/path/to/webroot/tree/
```

## Технологии

- Фронт: чистый JS + [3d-force-graph](https://github.com/vasturiano/3d-force-graph)
  (вендорится в `vendor/graph-bundle.js`)
- Бэкенд: стандартная библиотека Python (`http.server` + `sqlite3`)
